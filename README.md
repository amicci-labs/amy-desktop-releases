# Amy Desktop

Aplicativo da Amy para macOS, Windows e Linux.

Este repositório distribui somente instaladores e metadados de atualização. O desenvolvimento acontece em um repositório privado.

As versões oficiais estarão disponíveis em [Releases](https://github.com/amicci-labs/amy-desktop-releases/releases) após a validação e assinatura dos pacotes. Ainda não há uma versão oficial publicada neste canal.

Na primeira instalação, escolha o pacote do seu sistema. Nas versões oficiais com atualização automática, a Amy avisa quando uma nova versão está disponível, pede confirmação para baixar e permite escolher quando reiniciar. As conversas salvas e a conta são mantidas.

- macOS: DMG para Apple Silicon (arm64) ou Intel (x64).
- Windows: instalador EXE x64.
- Linux: AppImage x64 para atualização pelo aplicativo; DEB pelo gerenciador de pacotes.
